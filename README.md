# 마포구청 콘텐츠 위생관리 (콘텐츠 건강검진)

공공기관 홈페이지가 AI(RAG 챗봇·AI 검색)의 원료로 쓰이기 전에, 그 원료의 상태를 검진하고 정비 순서를 정해 주는 도구의 **파일럿 화면(Next.js)** 구현입니다.

- 기획서: `콘텐츠위생앱_기획서.md` · 구현 명세: `콘텐츠위생앱_구성명세서.md` (짝 문서)
- 코드명 `hygiene` · 1차 적용 대상 마포구청 홈페이지

## 짝 앱: 마포구청 AI 웹핸드북

https://mapo-ai-handbook.vercel.app — 핸드북은 '왜·무엇을'(강의·시장조사·과별 프롬프트), 이 앱은 '어떻게'(전수 스캔·승인·산출물)입니다. 핸드북에서 가져온 것:

- 디자인 체계(IBM Plex Sans KR·Mono, Gowun Batang, ink·sky·paper·line 토큰, 44px 격자 배경, eyebrow·chip), 밝게/어둡게 전환, 인쇄 규칙
- 통합검색 `/` 또는 `Ctrl+K`, 매뉴얼·도움말 화면, 푸터 표기
- 영역 ③ '네 가지 과업'(위생·구조화·쉬운 우리말·신선도 감시)과 측정 지표 → 대시보드
- 현장 테스트 10문항의 함정 문항(민선8기·코로나) → D3 이슈 증거에 '평가셋 문항' 태그
- 2026.8.14 조직개편 후 부서 목록(2담당관 37과·보건소 4과·16동) → `src/data/org.ts`, D3 조직 불일치 대조·부서 선택

## 이 저장소가 담는 것 / 담지 않는 것

- **담는 것**: 화면 5종, 검사 도구, TypeScript로 옮긴 핵심 규칙(URL 정규화·개인정보·title 규칙·준비도 판정·위생 점수·이슈 지문)과 단위 테스트, 내보내기 산출물 생성기, 회귀 사례 F1~F9를 재현하는 **시연용 표본 데이터**.
- **담지 않는 것**: Python 수집기·탐지기 코어, PostgreSQL, LLM 어댑터. 명세서 13장 S0~S12는 별도 `hygiene` 패키지로 구현한다.
- Vercel(서버리스)에는 DB가 없으므로 승인·규칙·대표 URL 변경은 **브라우저 localStorage**에 보관한다. 파일럿에서는 FastAPI + PostgreSQL로 대체한다.
- 표본 데이터의 사이트·URL·수치는 강의안(2026-09-12 색인 기준) 관찰과 명세서 예시를 바탕으로 한 **설명용**이다. 실제 값은 첫 크롤에서 확정한다.

## 설계 원칙 (기획서 5장)

1. 읽기만 한다 — 모든 처분은 사람이 승인. 삭제 제안 없음(보관 + 색인 제외).
2. 산출물은 두 갈래 — 수정 요청서(느림) + 매니페스트(빠름).
3. 싼 판단 먼저 — 규칙 → 유사도 → LLM → 사람.
4. 측정되는 도구 — 정밀도 90% 미만 탐지기는 '관찰' 등급.


## 담당자 화면 개선 (2026-09-22)

- 시연 환경과 브라우저 내 저장 범위를 모든 화면 상단에 안내합니다.
- 검토 목록은 전체 유형을 기본으로 표시하며, 대기·재발 필터와 긴급 순 정렬을 제공합니다.
- 키보드 처리 단축키는 기본으로 꺼져 있습니다. 목록 아래에서 켤 수 있습니다.
- 일괄 처리는 건수·처리 내용을 확인한 후 실행하며, 결과 메시지를 표시합니다.
